Admin setup

You're seeing this because config.js isn't in the GitHub repo yet. Only you do this once. After you upload the file, everyone who opens the link only sees the password screen, and all data is shared and live.

  1. Open console.firebase.google.com → Add project (free).
  2. Build → Firestore Database → Create database → pick a region (e.g. asia-south1) → Start in test mode.
  3. Project settings (gear icon) → Your apps → click </> → register the app → copy the whole firebaseConfig block it shows.
  4. Paste it below, set a password, and click Generate config.js.
